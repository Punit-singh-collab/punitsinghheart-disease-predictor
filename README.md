# ❤️ Heart Disease Predictor

A machine learning project that predicts heart disease risk
using the Cleveland Heart Disease dataset.

## Models Used
- Random Forest (AUC: 0.953) ✅ Best
- Gradient Boosting (AUC: 0.941)
- Logistic Regression (AUC: 0.891)

## How to Run
pip install scikit-learn pandas numpy
python heart_disease_predictor.py --demo

- 13 clinical inputs
